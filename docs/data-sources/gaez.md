## What it is

GAEZ is FAO and IIASA's world map set of how well each crop can grow in each place: growing-season length, climate classes, crop suitability classes, attainable yield (rain-fed or irrigated, low or high inputs), actual yields and yield gaps, for a past climate and for future climate scenarios.
GAEZ v4 (the one on the challenge page) is a 5 arc-minute grid (about 9 km), climate 1981-2010; **GAEZ v5 was launched on 14 April 2025** (read) with a 30 arc-second grid (about 1 km), climate 2001-2020 from AgERA5, 78 crop codes, and a more open licence.

Coverage: global. Barrie, Ontario and Ames, Iowa both return values (checked).

## Where the second check differed

1. FAO WMTS map tiles: the first check rated it "broken, working address not confirmed". The service is up; only the address template printed in FAO's catalogue is wrong. The service's own GetCapabilities gives a different template, and that one returned a real tile (200, 24.7 kB PNG of the Great Lakes area, maize suitability). The working address is in the table above.
2. The GAEZ v5 maize file on Google is 30.9 MB (first check: about 25 MB). The GAEZ CKAN answer was 98 kB (first check 72 kB).
3. Licence noticed in the CKAN answer (read): GAEZ v5 records say CC-BY-4.0; the GAEZ v4 record (RES06-YLD2) says CC-BY-NC-SA-4.0, which is non-commercial.
4. Everything else matched the first check's status.

## Terms

- **GAEZ v4: non-commercial.** The FAO catalogue record "Yield (Global - ~9 km) - GAEZ v4" carries "Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International" (checked in the catalogue answer; the second check also read CC-BY-NC-SA-4.0 on the RES06-YLD2 record). I think the v4 portal itself states CC BY-NC-SA 3.0 IGO; its terms page is script-only and was not read. Either way: a free public site with no adverts may use v4 with credit and share-alike; **a business may not** without FAO's permission.
- **GAEZ v5: CC BY 4.0** on the individual v5 dataset records (crop suitability 1 km and 10 km, agro-climatic resources, land and water resources, actual yields, yield gaps) (checked). One inconsistency: the group record "Suitability and Attainable Yield - GAEZ v5" itself is tagged CC BY-NC-SA 4.0 while its member datasets are CC BY 4.0 (checked). Worth one email to FAO before commercial use.
- FAO database terms (read at https://www.fao.org/contact-us/terms/db-terms-of-use/en/): default licence CC BY 4.0 unless the metadata says otherwise; datasets "shall not be used for or in conjunction with the promotion of a commercial enterprise"; no implied FAO endorsement; provided "without warranty of any kind".
- Credit line asked for (read): "FAO. [year of last update]. [Name of database: Name of dataset]. Accessed [date]. [URL]. Licence: CC-BY-4.0." For GAEZ, credit FAO and IIASA (I think the exact GAEZ v4 citation is "FAO and IIASA. 2021. Global Agro-Ecological Zones v4"; not re-read).
- Rate limits: none stated for the ArcGIS services, the GISMGR API or the buckets (not read). ArcGIS query limit is 1000 records per call (checked).

## Problems

1. The challenge page points to **GAEZ v4, which has been superseded by GAEZ v5** (launched 14 April 2025): v4 is 9 km, climate 1981-2010 and non-commercial; v5 is 1 km, climate 2001-2020 and CC BY 4.0.
2. v4 S3 bucket listing is denied (403); files can only be found through the image-service catalogue (`download_url`). The bucket name contains "gaezdev" and files date from March 2020: it looks like a development bucket left in service (I think), so it may vanish.
3. FAO WMTS: the tile address template published in FAO's own catalogue does not work (missing `style`, wrong tile-matrix-set name). The second check found that the template in the service's own GetCapabilities works (see the table).
4. FAO GeoServer WMS for v4 (`io.apps.fao.org`) answered 502 twice in each check.
5. `gaez.fao.org` and `data.apps.fao.org/gaez/` are script-only pages: documentation and terms text cannot be read by a plain fetch.
6. Licence tags are inconsistent inside the FAO catalogue for v5 (one group record NC-SA, the datasets CC BY).
7. The v4 ArcGIS server is version 10.81 (2020) with empty description and copyright fields; no sign of maintenance, though it answered every call in about 1 s.
8. GISMGR lists return 20 items per page by default (`hasNext: true`); use `size=`.
9. GAEZ is a coarse model answer (1 km at best, average climate over 20-30 years, generic management): it says what suits the district, not this field in this year.

## Recommendation

Use GAEZ v5 from the public Google bucket by HTTP range read (index from the GISMGR API): about 11 small requests and 28 kB per crop per point, no key, CC BY 4.0.
Show the farmer, for each crop in the rotation, FAO's suitability class for the field's square today (2001-2020) and for 2041-2060, as an independent second opinion beside Crophalo's own score; keep v4's ArcGIS identify call only as a fallback (and not once the site is a business). The working WMTS template can give a matching map layer.

## How Crophalo uses it

Crophalo does not use it yet. From FAO, Crophalo uses FAOSTAT (production and price zips), and it has its own crop-fit scoring; GAEZ, agro-ecological zones and FAO's suitability maps are not used.
