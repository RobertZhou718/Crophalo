# The project's rules and the checks that prove them

Each rule of the project has a line here. The last column names the check that proves it: the suite file in `scripts/`, then the check's own name, exactly as the suite prints it when it fails. A rule that no suite can see says "kept by review": it is read by a person before each release. `node scripts/test.mjs` reads this file: every rule must have a line, every suite named must exist, and every check name must be found in its suite.

| Id | Rule | Proof |
|---|---|---|
| R01 | No helper program, model or coding tool is named anywhere in the project: not in code, comments, documents, file names or signed lines. The one exception is the README's general statement that SI coding tools helped, which names none. | test.mjs: no helper program, model or coding tool is named in the project; test.mjs: no file or folder is named after one; test.mjs: no line signs a file as made by a tool; test.mjs: the README says SI tools helped write the code, and that the app itself does not use SI |
| R02 | No framework, no bundler, no build step, no package files; the three libraries are copied into the project with their licences. | test.mjs: no package file, lock file, node_modules or bundler setting anywhere (no framework, no build step); test.mjs: each library keeps its licence beside it; test.mjs: the versions are the ones the app is built on: Leaflet 1.9.4, MapLibre GL 4.7.1 with its Leaflet plugin, three.js r160 |
| R03 | The country is written "Türkiye", everywhere. | test.mjs: "Türkiye" is how the project writes it; test.mjs: the country code TR is always Türkiye, whatever name came with it |
| R04 | The project's own code is under the Apache License 2.0, and the README names it and the licence of every bundled library. | test.mjs: LICENSE is the Apache License 2.0 exactly as published, byte for byte; test.mjs: the README has a Licence part that names the Apache License 2.0 and the LICENSE file; test.mjs: the README names the licence of every bundled library |
| R05 | A page loads nothing from an outside address: no script, style, font, picture or library host. Only the data services are called, and only when a reading is asked for. | test.mjs: no page loads a script, style, font or picture from an outside address; test.mjs: the only early connections are to the data services; test.mjs: no script imports code from outside; test.mjs: no library or font host is named in the app at all |
| R06 | Exactly six views, in their order; no new top-level tab or navigation item without the owner's written yes. | test.mjs: exactly the six views, in their order |
| R07 | The app starts and answers with no key and no login. | R12 | Nothing in the project, and no file's metadata, is dated before 14 November 2026. Outside data keeps its own honest dates. | test.mjs: no file is older than 2026-11-14 (the build began that day); test.mjs: no date before 2026-11-14 is written anywhere in the project (data ranges are listed with their reason) |
| R13 | The project promotes no commercial product or service; a provider appears only as a plain credit line. | kept by review |
